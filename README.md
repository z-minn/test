## ✨ 功能特色

- **24 节气罗盘** — 可视化圆形罗盘，点击节气节点展开详情
- **四季专属配色** — 春季粉紫、夏季翠绿、秋季金橙、冬季霜蓝
- **诗意卷轴弹窗** — 古典卷轴设计，展示节气三候与诗词
- **精美壁纸上生成** — 支持生成手机/电脑壁纸，一键保存
- **粒子星河流转** — 动态粒子背景，营造深邃夜空氛围
- **响应式布局** — 适配桌面端与移动端

## 🛠️ 技术栈

- **HTML5 + CSS3 + Vanilla JavaScript** — 零依赖，纯原生实现
- **SVG** — 节气罗盘矢量图形
- **Canvas API** — 粒子星空动画
- **CSS Variables** — 四季主题色切换
- **LocalStorage** — 本地壁纸生成

## 📖 灵感来源

本项目以中国传统二十四节气文化为灵感，将天文、历法、农事与诗词融为一体，以现代交互设计重述古典岁时之美。
